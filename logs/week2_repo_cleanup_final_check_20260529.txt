三、关键事实口径更新

1. FP32 serving baseline 已完成，包括 API ready、smoke test 和 batch-profile benchmark。
2. W8A8 compressed-tensors 是当前稳定完成的 8-bit 权重量化 serving 路径。
3. bitsandbytes INT8、INC INT8 和 compressed-tensors strict INT8 均已进行可行性探测和失败边界记录，但没有成为最终稳定 serving 路径。
4. W8A8 相比 FP32 在同参数 batch-profile benchmark 下提升了 QPS 和 output tokens/s。
5. model loading memory 从约 67.59 GiB 降至约 17.71 GiB，下降约 73.8%；但不能表述为 runtime nvidia-smi 总显存同比下降，因为 vLLM 会将释放出来的显存重新用于 KV cache。
6. 128K serving profile live boundary test 已完成，覆盖 conservative、near-limit 和 over-limit 三类请求。
7. 512K full-context 实机验证仍未完成。
8. FP8 KV cache 仍未完成。
9. Seed-Coder 专项模型部署和评测仍未完成。
