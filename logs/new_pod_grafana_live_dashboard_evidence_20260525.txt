===== 截图中观察到的指标 =====
1. FastAPI Request Rate：API 请求速率在负载期间出现明显峰值。
2. FastAPI P95 Latency：负载期间 P95 延迟出现明显变化，可用于观察尾延迟。
3. vLLM Running / Waiting Requests：running requests 最高达到 2，说明 vLLM 正在处理并发请求；waiting requests 为 0，说明当前负载下没有明显排队。
4. vLLM KV Cache Usage：KV cache usage 在推理期间出现非零变化，说明监控覆盖到了大模型推理中的核心缓存资源。
5. vLLM Prefix Cache Queries / Hits：prefix cache 查询与命中指标出现变化，可用于观察缓存行为。
6. vLLM Prompt / Generation Tokens：prompt tokens 与 generation tokens 出现增长，说明监控对象是真实 LLM 推理负载，而不是普通 HTTP 服务。

===== 证据价值 =====
该截图证明 Prometheus + Grafana 已经接入 FastAPI 与 vLLM，并且能在 Seed-OSS-36B 真实推理负载下展示请求速率、P95 延迟、并发请求、KV cache、prefix cache 和 token 相关指标。
