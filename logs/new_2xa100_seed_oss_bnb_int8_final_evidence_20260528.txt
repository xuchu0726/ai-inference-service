Engineering interpretation:
The bitsandbytes quantization path successfully served Seed-OSS-36B through vLLM, but it did not meet the expected optimization target of >=30% memory reduction and >=20% speed improvement in this setup. The measured serving memory reduction was limited because nvidia-smi reports total runtime allocation, including vLLM engine memory and KV cache reservation, not only quantized model weights. Throughput also decreased, suggesting that this online bitsandbytes path introduces runtime overhead and is not an ideal high-throughput serving optimization for this model/configuration.

This result should be reported as a real serving trade-off rather than a failed experiment. The next higher-value step is to compare FP32 against another quantization/precision serving profile or tune vLLM scheduling/KV-cache parameters to produce a defensible optimization path.
