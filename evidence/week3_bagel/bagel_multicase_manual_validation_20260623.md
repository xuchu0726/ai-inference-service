# BAGEL 三案例人工核验结论

## 核验范围

本次核验针对三张 BAGEL 官方测试图像的图像理解 API 输出进行人工对照。每个案例使用固定 prompt、固定推理参数，并执行 3 次请求。由于 `do_sample=false`，同一案例的 3 次输出一致。

判定原则：仅将图中可直接观察或直接读取到的内容视为支持证据；无法由图像无歧义确认的具体属性、身份或背景信息标记为过度具体描述风险。

## official_meme

- 结论：通过。
- 支持证据：模型正确识别三段式排版，以及考试手写从前两页、中间页到最后两页的对比主题。
- 边界：模型未明确描述最后一段呈现为类似心电图的线条，属于细节遗漏，不构成错误或幻觉。

## official_octupusy

- 结论：通过，属于 OCR/图文联合理解主导案例。
- 支持证据：图中蓝色说明牌直接包含作品名称、设计者、年龄、年份、艺术家、Museum of Glass、赞助信息，以及关于 “Octopus bandit” 的引文。模型输出中的对应具体信息可由图片文字直接支持。
- 边界：该案例主要验证了图中文字读取与图像主体结合的能力；不得将这些具体信息解释为模型仅根据雕塑外观自行推断得到。

## official_women

- 结论：部分通过。
- 支持证据：模型正确识别红色外套、女性主体、灰色石墙背景、深色头发和手托脸姿势。
- 过度具体描述风险：模型将右下角仅部分可见的白色图案明确命名为“小狗刺绣”。当前图像无法无歧义确认完整图案类别，因此该描述不应作为可靠视觉结论。
- 工程含义：面向低风险图像描述，服务可提供可用结果；面对需要精确识别局部细节、实体属性或高风险视觉判断的场景，应增加置信度控制、人工复核或结构化视觉验证。

## 总结

三案例共 9/9 请求成功。模型在固定输入和 `do_sample=false` 条件下输出稳定，能够完成图像主体、场景和图中文字描述。案例同时显示：输出质量依赖图像信息类型；对局部或不完整视觉证据，模型可能产生过度具体描述。因此当前服务适合作为受控图像理解能力验证，不应直接用于高风险自动决策。
