# 电商商品图文生成案例人工核验

## 场景

输入商品图片与受限商品文案 prompt，要求生成标题、三条卖点和一条不可确认信息。

## 运行结果

- 请求次数：3
- 成功次数：3
- P50：3.878 秒
- P95：3.926 秒
- 峰值显存：29773 MiB
- 峰值 GPU 利用率：74%
- 三次输出一致。

## 输出质量判定

结论：技术可行，但不满足“仅基于图片可见信息”的严格约束。

模型输出中的“耐用材质”“适合户外使用”“彰显品质”“便于分类存放摄影器材”均无法仅由图片直接确认；“户外摄影包”也属于过度具体分类。模型虽然正确将容量列为不可确认信息，但未能同时约束其他不可见属性。

## 工程含义

该案例证明图像加文本输入可以生成稳定的商品标题和卖点草稿，但不能直接作为自动发布的商品文案。上线前应增加商品属性白名单、结构化商品库校验、风险词拦截和人工复核。
