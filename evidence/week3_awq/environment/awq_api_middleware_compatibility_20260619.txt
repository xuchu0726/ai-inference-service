AWQ 服务 API 中间件兼容性记录

一、模型服务状态
AWQ-Marlin 模型已完成加载，KV cache 已初始化，服务进程达到 Application startup complete。

二、API 故障现象
访问 /v1/models 和 /v1/chat/completions 时返回 500 Internal Server Error。

三、根因
异常发生于 prometheus_fastapi_instrumentator 的路由解析阶段：
AttributeError: '_IncludedRouter' object has no attribute 'path'

该异常发生在 HTTP API 中间件层，不发生在模型加载、AWQ-Marlin kernel、GPU 通信或推理引擎层。

四、环境版本
- vLLM: 0.11.2
- FastAPI: 0.137.2
- Starlette: 1.3.1
- prometheus-fastapi-instrumentator: 8.0.0

五、处理决策
保留原始服务启动日志与 500 错误输出；
固定 FastAPI、Starlette 与 Prometheus 中间件至与 vLLM 0.11.2 兼容的版本后重新启动服务。
